# Site de pizzaria

Projeto multipágina construído para praticar navegação consistente, organização de conteúdo comercial e formulários.

## Estrutura

- `home.html`: apresentação e entrada principal;
- `cardapio.html`: organização de produtos;
- `promocao.html`: comunicação de ofertas;
- `delivery.html`, `reservas.html` e `contato.html`: fluxos de interação;
- `franquias.html`: apresentação de unidades/ambientes;
- `pizzaria.css`: identidade visual compartilhada.

## Aprendizados

Hierarquia visual, links entre páginas, reutilização de estilos, formulários sem backend e separação entre estrutura e apresentação. Imagens não foram publicadas porque sua licença não pôde ser confirmada.
