# Site institucional de curso

Desenvolvi este protótipo acadêmico como uma página informativa com formulário de inscrição.

Baseei o projeto em uma jornada simples: apresentar o curso, destacar informações úteis e conduzir a pessoa interessada ao formulário. Com ele pratiquei estruturação semântica básica, campos de cadastro e organização visual.

Em produção, o formulário precisaria de backend, conexão HTTPS, consentimento explícito, validação no servidor, política de retenção e proteção dos dados pessoais. Nenhum dado preenchido é armazenado por este protótipo.
