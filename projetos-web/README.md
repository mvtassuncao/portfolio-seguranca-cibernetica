# Projetos de desenvolvimento web

Projetos produzidos para praticar HTML, CSS, JavaScript, navegação multipágina, formulários e organização visual.

As mídias cuja origem ou licença de redistribuição não pôde ser confirmada foram removidas da versão pública. Assim, alguns caminhos de imagem permanecem no HTML como evidência da estrutura original, mas a publicação concentra-se no código autoral.

- [Site de pizzaria](pizzaria/) — arquitetura de informação para cardápio, promoções, reservas, contato, delivery e unidades.
- [Site institucional de curso](site-curso/) — divulgação de curso e formulário de inscrição.
- [Site temático de artista](site-artista/) — páginas de biografia, discografia, notícias, galeria e contato, com scripts de interação e validação.
