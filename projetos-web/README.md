# Projetos de desenvolvimento web

Nesta área reuni os projetos que desenvolvi para praticar HTML, CSS, JavaScript, navegação multipágina, formulários e organização visual.

Removi da versão pública as mídias cuja origem ou licença de redistribuição não consegui confirmar. Por isso, alguns caminhos de imagem permanecem no HTML como evidência da estrutura original, mas concentrei a publicação no código que desenvolvi.

- [Site de pizzaria](pizzaria/) — arquitetura de informação para cardápio, promoções, reservas, contato, delivery e unidades.
- [Site institucional de curso](site-curso/) — divulgação de curso e formulário de inscrição.
- [Site temático de artista](site-artista/) — páginas de biografia, discografia, notícias, galeria e contato, com scripts de interação e validação.
