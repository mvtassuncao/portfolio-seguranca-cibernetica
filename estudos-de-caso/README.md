# Estudos de caso sanitizados

Descrevi os casos desta seção no [catálogo principal](../catalogo.md). Mantive fora da publicação os documentos originais que continham dados sensíveis, evidências de alvos, hashes, tokens, flags, credenciais ou marcação de confidencialidade.

Nas sínteses preservei quatro elementos profissionais: contexto e escopo, método, classe de risco e recomendação. Assim consigo apresentar meu raciocínio técnico sem aumentar o risco para terceiros.
