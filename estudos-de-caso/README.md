# Estudos de caso sanitizados

Os casos desta seção são descritos no [catálogo principal](../catalogo.md). Os documentos originais que continham dados sensíveis, evidências de alvos, hashes, tokens, flags, credenciais ou marcação de confidencialidade foram deliberadamente mantidos fora da publicação.

As sínteses preservam quatro elementos profissionais: contexto e escopo, método, classe de risco e recomendação. Essa forma de documentação permite avaliar o raciocínio técnico sem aumentar o risco para terceiros.
